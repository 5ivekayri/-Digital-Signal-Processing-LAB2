## Что нужно понять

ДПФ представляет N отсчетов сигнала как сумму N комплексных гармоник. Матрица W содержит эти гармоники; умножение X=W*x дает спектр. Модуль X показывает величину спектральных составляющих, аргумент — их фазу. Частота дискретизации не задана, поэтому по горизонтали графиков указан номер k, а не герцы.

Прямое ДПФ: `X[k] = sum(x[n]*exp(-j*2*pi*k*n/N))`.
Обратное: `x[n] = (1/N)*sum(X[k]*exp(+j*2*pi*k*n/N))`.
Суммы идут от 0 до N-1. В MATLAB элемент с математическим номером 0 записывается как `x(1)`. `1i` используется вместо переменной `j`, чтобы случайно не переопределить мнимую единицу.

## Неточности и соглашения

- В кратком предварительном задании написано N=4. По твоему указанию используем вариант 5 из полной таблицы: N=8.
- На стр. 76 нечетная последовательность `{0,x[1],x[2],x[3],-x[3],-x[2],-x[1]}` содержит **7 элементов**. Это корректный циклически нечетный сигнал для N=7. Код показывает его буквально и отдельно вариант для N=8: `{0,x[1],x[2],x[3],0,-x[3],-x[2],-x[1]}`. Для циклической нечетности при четном N отсчеты 0 и N/2 должны быть нулевыми. Оба случая явно подписаны.
- Четность понимается циклически: `x[n]=x[(-n) mod N]`, а не как обычное отражение массива.
- Матрица Q переставляет `[X0,X1,…,X7]` в `[X0,X7,…,X1]`; нулевой элемент остается первым. Используется тождество `W²=N*Q`, поэтому `x=W*Q*X/N`.
- В MATLAB `'` — сопряженное транспонирование, `.'` — обычное. Для обратной матрицы используем `conj(W)/N` (W симметрична).
- При |X[k]|≈0 фаза не определена. На графике такой отсчет пропущен (`NaN`), а не выдан за фазу 0. Для сравнения фаз при сдвиге учитывается период 2*pi.
- Графики показывают ненормированный двухсторонний модуль ДПФ `abs(X)`, не односторонний спектр амплитуд `2*abs(X)/N`.
- Формальный прямой расчет для N=8: 64 комплексных умножения и 56 комплексных сложений (без построения W). Это счет общего алгоритма; вещественные входные данные и специальные множители допускают упрощения. БПФ имеет порядок O(N*log2(N)), но здесь основной расчет намеренно матричный.

# Шпаргалка для защиты — вариант 5

## 1. Главная идея работы

**Сигнал во времени** — набор отсчетов `x[n]`. **Спектр** — набор комплексных коэффициентов `X[k]`, показывающих вклад гармоник в этот сигнал. ДПФ переводит одно представление в другое без потери информации, если сохранить все комплексные коэффициенты. Один модуль спектра не сохраняет фазу и в общем случае недостаточен для восстановления.

ДПФ работает с конечным блоком из N отсчетов. При рассуждениях о сдвигах, четности и индексах этот блок рассматривается как один период последовательности: индексы берутся по модулю N. Поэтому сдвиг в работе именно циклический.

Комплексная экспонента — удобная запись синуса и косинуса:

```text
exp(jθ) = cos(θ) + j sin(θ),    j² = −1.
```

Каждая строка матрицы W содержит комплексную гармонику. Умножение строки на сигнал и суммирование определяет соответствующий коэффициент спектра. Различные гармоники ортогональны, поэтому их вклады можно разделить и затем восстановить сигнал.

## 3. Основные формулы

### Прямое и обратное преобразования

```text
X[k] = Σ(n=0…N−1) x[n] · exp(−j·2πkn/N).
x[n] = (1/N) · Σ(k=0…N−1) X[k] · exp(+j·2πkn/N).

W[k,n] = exp(−j·2πkn/N).
X = W·x.
W⁻¹ = Wᴴ/N = conj(W)/N, поскольку Wᵀ = W.
x = W⁻¹·X.
```

В прямом преобразовании знак экспоненты отрицательный. В обратном — положительный и есть множитель 1/N. В коде `W(k+1,n+1)` соответствует математическому `W[k,n]`.

Для `X[k]=A+jB`:

```text
|X[k]| = sqrt(A²+B²).
φ[k] = arg(X[k]) = atan2(B,A).
X[k] = |X[k]| · exp(jφ[k]).
```

В MATLAB используем `abs` и `angle`, а не `atan(B/A)`: `angle` правильно учитывает четверть комплексной плоскости. При нулевом модуле фаза математически не определена. Фазы, отличающиеся на 2π, эквивалентны; −π и +π описывают одно направление.

### Частотная ось и нормировка

Если известна частота дискретизации `Fs`, то шаг частот равен `Δf=Fs/N`, а номера ДПФ соответствуют частотам `k·Fs/N` по модулю Fs. Для четного N индексы выше N/2 обычно интерпретируют как отрицательные частоты `(k−N)·Fs/N`. Частота дискретизации в этой работе не задана, поэтому используем номер k.

`X[0]=Σx[n]` — постоянная составляющая в ненормированном ДПФ; **среднее значение сигнала равно X[0]/N**. Здесь X[0]=13, среднее 13/8=1.625. При N=8 коэффициент X[4]=−19 соответствует чередующейся гармонике `(-1)^n`.

В графиках показан **двухсторонний ненормированный модуль** `abs(X)`. Для одиночной вещественной синусоиды, точно попадающей в частотный отсчет, ее амплитуду получают как `2*abs(X[k])/N` для внутренней положительной частоты. Постоянную составляющую и частоту Найквиста при четном N не удваивают. Это другая нормировка, в нашей работе она не применяется.

### Свойства дискретных экспоненциальных функций (предварительное задание)

Обозначим `w_k[n]=exp(−j·2πkn/N)`.

| Свойство | Формула | Смысл и проверка |
|---|---|---|
| Ортогональность | `Σ w_k[n]·conj(w_l[n]) = N` при k=l, иначе 0 | Разные гармоники не смешиваются; `W*W'=N*I`. |
| Периодичность | `w_k[n+N]=w_k[n]`, `w_(k+N)[n]=w_k[n]` | Индексы повторяются через N; код проверяет сдвиг индекса на N. |
| Симметричность матрицы | `W[k,n]=W[n,k]`, `W=Wᵀ` | Произведение kn не меняется при перестановке индексов; проверяем `W-W.'`. |
| Мультипликативность | `w_a[n]·w_b[n]=w_((a+b) mod N)[n]` | При умножении экспонент их показатели складываются; проверяем поэлементное произведение строк. |

W симметрична, но в общем случае **не является эрмитовой**: `W=W.'` не означает `W=W'`. Строки W имеют норму √N; унитарной является нормированная матрица `W/√N`.

### Восстановление через матрицу перестановок — задание 3

```text
Q·[X0; X1; X2; X3; X4; X5; X6; X7]
 = [X0; X7; X6; X5; X4; X3; X2; X1].

Q² = I,    W² = N·Q,    W·Q = conj(W).
x = W·Q·X/N.
```

Это второй способ вычислить обратное ДПФ с помощью той же матрицы прямого преобразования. Дважды примененное прямое ДПФ дает циклически обращенный сигнал, умноженный на N. Q исправляет обращение, а деление на N — масштаб. Здесь `W²` означает матричное `W*W`, а не поэлементное `W.^2`.

### Линейность — задание 4

```text
F{a·x+b·y} = a·X+b·Y.
```

Преобразование суммы равно сумме преобразований с теми же коэффициентами. В коде сравниваем `W*(a*x+b*y)` и `a*(W*x)+b*(W*y)`. Это свойство позволяет анализировать сложный сигнал по частям.

### Вещественность, четность и мнимый сигнал — задания 2 и 5

```text
Вещественный x:  X[(−k) mod N] = conj(X[k]).
Четный x:        x[(−n) mod N] = x[n].
Нечетный x:      x[(−n) mod N] = −x[n].
```

- У вещественного сигнала спектр сопряженно-симметричен: модуль четный, фаза меняет знак по модулю 2π там, где она определена. Сам спектр может быть комплексным.
- У вещественного циклически четного сигнала спектр вещественный. Его ненулевые коэффициенты имеют фазу 0 или ±π.
- У вещественного циклически нечетного сигнала спектр чисто мнимый. Фаза ненулевых коэффициентов равна ±π/2.
- У чисто мнимого сигнала `s=j*x`, где x вещественный, `S=j*X`. Его спектр в общем случае комплексный: модуль прежний, фаза увеличивается на π/2 по модулю 2π. Выполняется `S[(−k) mod N]=−conj(S[k])`.

Почему нужны нули у нечетного сигнала? При n=0 условие требует `x[0]=−x[0]`, значит x[0]=0. При четном N индекс N/2 тоже переходит сам в себя, поэтому x[N/2]=0. Для N=8 это индексы 0 и 4.

### Теорема о циклическом сдвиге — задание 6

```text
x_m[n] = x[(n−m) mod N]             — сдвиг вправо.
X_m[k] = X[k] · exp(−j·2πkm/N).
|X_m[k]| = |X[k]|.
φ_m[k] = φ[k] − 2πkm/N  (mod 2π).
```

Множитель сдвига имеет модуль 1, поэтому меняется только фаза. Здесь `circshift(x,m)` переносит вышедшие справа отсчеты в начало. Для m=4 и N=8 множитель равен `exp(−jπk)=(-1)^k`. Для m=6 — `exp(−j·3πk/2)`.

Фазы сравниваем через угол комплексной экспоненты:

```text
δφ[k] = angle(exp(j·(angle(X_m[k]) − angle(X[k]) + 2πkm/N))).
```

Это убирает ложную разность 2π на границе −π/+π. Точки с почти нулевой амплитудой из проверки фазы исключаются.

**Операторы MATLAB:** `*` — матричное умножение, `.*` — поэлементное; `^` — матричная степень, `.^` — поэлементная; `'` — сопряженное транспонирование, `.'` — обычное. Вектор сигнала в коде — столбец, чтобы произведение `W*x` имело размер N×1.

**Сложность:** для каждого из N спектральных отсчетов прямое ДПФ использует N умножений и N−1 сложений. Итого N² умножений и N(N−1) сложений: при N=8 это 64 и 56. Порядок — O(N²); память для W — O(N²). Это формальный счет общего комплексного алгоритма без построения матрицы и специальных упрощений. БПФ уменьшает порядок вычислений до O(N log N), вычисляя то же преобразование. Для маленького N важнее наглядность, а при больших N выигрыш БПФ существенен.

## 7. Короткие ответы на вопросы преподавателя

**Чем ДПФ отличается от БПФ?** ДПФ — математическое преобразование. БПФ — семейство эффективных алгоритмов для его вычисления. Результат при одинаковой нормировке один и тот же с учетом округления.

**Почему спектр комплексный, хотя сигнал вещественный?** Комплексный коэффициент содержит вклад косинусной и синусной составляющих, то есть информацию об амплитуде и фазе. Вещественность сигнала обеспечивает сопряженную симметрию, но не вещественность каждого коэффициента.

**Зачем делить на N в обратном преобразовании?** Потому что WᴴW=NI. Деление на N компенсирует масштаб и восстанавливает исходные отсчеты.

**Что такое гармоника k=0?** Постоянная составляющая. X[0] — сумма отсчетов, а X[0]/N — среднее значение.

**Почему на графике нет герц?** Не задана частота дискретизации. Известны только номера гармоник; при известной Fs шаг частот был бы Fs/N.

**Почему может быть скачок фазы от +π к −π?** Функция angle показывает главное значение аргумента. Эти направления совпадают по модулю 2π; скачок на 2π не означает физического изменения.

**Почему фаза в некоторых точках пропущена?** При нулевом модуле она не определена. У почти нулевого комплексного числа округление может давать произвольный угол, поэтому такие точки маскируются.

**Почему не используется flip для Q?** Обычный flip перенес бы нулевой отсчет в конец. Циклическое обращение сохраняет индекс 0 и меняет k на (−k) mod N.

**Почему модуль не меняется при сдвиге?** Спектр умножается на комплексную экспоненту единичного модуля. Меняется только угол.

**Чем циклический сдвиг отличается от сдвига с нулями?** При циклическом сдвиге вышедшие элементы возвращаются с другой стороны. При заполнении нулями часть блока меняется или теряется; эта проверяемая формула для N-точечного ДПФ относится к циклическому сдвигу.

**Почему нужна дополнительная нулевая точка в нечетном N=8?** Индекс 4 при циклическом обращении остается собой. Нечетность требует x[4]=−x[4], следовательно x[4]=0.

**Почему ошибки не равны строго нулю?** Double хранит числа с ограниченной точностью; значения экспонент и результаты суммирования округляются. Сравнение с допуском корректнее строгого равенства.

**Что делает assert?** Проверяет условие численно. Если погрешность превышает установленный допуск, выполнение останавливается с ошибкой.

**Зачем фиксировать случайный генератор?** Чтобы все задания, отчет и повторный запуск использовали одинаковые отсчеты. Сигнал случайно сгенерирован, но эксперимент воспроизводим.

**Нужна ли Simulink-модель?** Для рассмотренной лабораторной №2 работа выполнена MATLAB-скриптами и функциями: матрицы, спектры и проверки свойств ДПФ. Модель Simulink в этих заданиях не требуется.
